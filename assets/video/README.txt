Wedding invitation video goes here
==================================

Paste your video file in this folder with this exact name:

    invitation.mp4

Recommended format:
- MP4 (H.264 video + AAC audio), 16:9 landscape
- 720p or 1080p
- Under 20 MB if possible (faster on WhatsApp/mobile data)

The site already points to: assets/video/invitation.mp4
So after pasting the file you can upload this folder to Hostinger again — no code or config change needed.

Behaviour:
- The video appears only after the lifafa/cover is opened.
- Music stops automatically when the video starts.
- Music resumes (or shows a Tap to play button) when the video ends or is paused.

Optional:
- To use another filename, change "video" in ../config.json, run:
      npm run generate -- sanjoy-suparna-2026-12-13
  then upload again.
- To change the thumbnail shown before play, replace the "video_poster" path in config.json.
